Confirmed decisions, provisional defaults and unresolved decisions that the implementation follows. Existing blueprint IDs (PD, OD, AD) are kept; IMD-nn are implementation decisions introduced by the implementation specification. Change an entry only through a pull request that also updates every affected contract; new entries start as Proposed.
